# Packing POS

Flutter POS for packing services only, not courier/shipping transactions. Offline-first; local SQLite; Bluetooth thermal receipts (58/80mm); dimension-based pricing; open slat or closed board wooden packing; independent six-face settings; editable material quantities; transactions, payments, reports, backup/restore. Fixed slat gaps are never redistributed; leftover edge width is reported. Board area is calculated per face. Timber cut lengths are explicit because joint style and section orientation vary. APK delivery target: GitHub Releases, not Actions artifacts.
